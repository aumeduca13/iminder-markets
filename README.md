# Precios y cartera de práctica

Esta página sirve para aprender a invertir **sin dinero real**. Empiezas con 1.000 € ficticios y puedes comprar y vender Bitcoin, Solana y Take-Two. Ves al momento el valor de tu cartera, el precio medio de compra y si ganas o pierdes.

Bitcoin y Solana se actualizan solos cada 45 segundos (con CoinGecko). Take-Two no va en directo: muestra el último precio que se consultó al crear la página. Tu cartera se guarda en el navegador, no en GitHub.

Esto es dinero ficticio, para practicar.

## Cómo probarla en tu ordenador

1. Descarga `index.html` (y este README, si quieres).
2. Abre `index.html` con un doble clic: se abrirá en tu navegador.

No hace falta instalar nada ni ejecutar ningún comando.

## Cómo publicarla en GitHub Pages

Así cualquiera puede abrirla con un enlace, sin instalar programas:

1. Entra en [github.com](https://github.com) e inicia sesión (o crea una cuenta).
2. Pulsa **New** para crear un repositorio nuevo. Ponle un nombre, por ejemplo `cartera-practica`, déjalo público y pulsa **Create repository**.
3. En la página del repositorio, pulsa **Add file** y luego **Upload files**.
4. Arrastra hasta ahí los archivos `index.html` y `README.md` (o pulsa *choose your files* para elegirlos).
5. Pulsa **Commit changes**.
6. Arriba, entra en **Settings**.
7. En el menú de la izquierda, pulsa **Pages**.
8. En *Build and deployment*, en **Source**, elige **Deploy from a branch**.
9. En **Branch**, elige `main` y la carpeta `/ (root)`, y pulsa **Save**.
10. Espera uno o dos minutos y recarga la página de **Settings → Pages**. Te aparecerá un enlace como `https://tu-usuario.github.io/cartera-practica/`.

Cuando quieras cambiar algo, vuelve al repositorio, pulsa otra vez **Add file → Upload files** y sube el `index.html` nuevo (así se sustituye el anterior).
